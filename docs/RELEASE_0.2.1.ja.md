# NekoriEmojy 0.2.1

NekoriEmojy は Windows 向けのローカルスタンプ管理ツールです。カテゴリとノードによる整理、検索、クイックパネル、直接送信などの機能を備えています。

今回はインストーラー版とポータブル版に加え、必要に応じて使える文字認識コンポーネントを用意しています。

## 主な機能

- **カテゴリとノード**：複数階層のカテゴリ、サブカテゴリ、上部のカテゴリタブ、通常のスタンプと混在させて配置できる折りたたみ可能なノード。
- **自由な整理**：1枚または複数のスタンプのドラッグによる並べ替え、カテゴリの調整、タグ管理。
- **スタンプの検索**：名前・タグ検索、最近使ったスタンプ、アニメーションのプレビュー、GIF サムネイルの表示フレーム指定。文字認識（OCR）コンポーネントは必要に応じて導入できます。
- **すばやく使う**：クイックパネル、貼り付けによるインポート、クリック送信、ドラッグ送信。静止画スタンプを単一フレームの GIF として送信することも選べます。
- **外観とカスタマイズ：** ライト／ダークテーマ、テーマのアクセントカラーのリアルタイムプレビュー、アプリアイコンの変更、調整可能な画面レイアウト、多言語 UI。
- **インポートとデータ管理：** 独立したスタンプライブラリの保存、Nekori ネイティブリソースパッケージのインポート・エクスポート、Suzu 互換共有パッケージ、設定ファイルのバックアップ、SuzuEmojy の既存データや共有パッケージからのコレクション移行。

スクリーンショットや操作デモは、リポジトリの README を参照してください。

## ダウンロード

下の **Assets** から、用途に合ったファイルを選んでください。

- **インストーラー版**：インストーラーを実行してインストールします。
- **ポータブル版**：解凍後、同梱の説明に従って起動します。
- **任意導入の OCR コンポーネント**：スタンプ画像内の文字を認識する場合にだけ導入してください。通常のスタンプ管理には必要ありません。
- **ソースコード**：コードを読んだり、自分でビルドしたりしたい方向けです。

公開時の Assets にある実際のファイル名と説明に従ってください。インストーラー、ポータブル版、OCR コンポーネントの各パッケージを取り違えないようご注意ください。

## 更新と個人データ

更新前には、スタンプライブラリと個人設定のバックアップを推奨します。旧バージョンや別のスタンプ管理ツールから移行する場合は特にご注意ください。ライブラリと設定のディレクトリは同じとは限りません。更新のためにユーザーデータのディレクトリを直接削除しないでください。

## 既知の制限

- 現在は主に Windows x64 を対象としています。
- メインプログラムは汎用的な x64 環境を想定したビルドターゲットを採用していますが、AVX2 非対応の実機での検証はまだ完了していません。
- 文字認識は任意導入のコンポーネントで、初回利用時に必要なファイルを取得します。公開ダウンロード先は、このリリースに実際にアップロードされたアセットに従います。
- スタンプの送信やドラッグの挙動は、送信先アプリの受け取り方によって異なる場合があります。

## フィードバックと開発方法

個人で開発・保守している **Vibe Coding プロジェクト**で、コードの多くは AI の支援を受けて作成・改善しています。不具合があった場合は、可能な範囲でアプリのバージョン、再現手順、関連するエラーメッセージを添えて、リポジトリの Issues にご報告ください。
