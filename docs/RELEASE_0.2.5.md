# NekoriEmojy 0.2.5

本次更新改善了分类浏览、搜索和动态图片显示，新增自动分类图标与本地故障报告，并修复多项拖放、排序及图片导入问题。

## 新增功能与优化

- **分类排序与搜索**：分类栏支持独立切换显示排序方式。搜索范围可在「当前分类（HERE）」和「全部资源（ALL）」之间切换。
- **自动分类图标**：支持按需自动为分类选取图标，优先保留已手动设置的图标。
- **统一图片代表帧**：动态图片选定的代表帧现在可以用于图库、分类图标、软件图标和快速面板。
- **动态图片标记**：为多帧图片增加可关闭的 `ANIM` 标记。缩略图帧选择器新增上一帧、下一帧按钮。
- **分类数量统计**：分类标题现在会统计下层子分类中的图片，并自动合并重复计数。
- **图标模式**：改善分类展开、收起及选中状态的显示，多层分类浏览更加直观。
- **本地故障报告**：程序意外退出后，下次启动会自动保存本地故障报告，并提醒用户查看。

## 问题修复

- 修复从系统托盘重新打开程序时，图库可能跳回旧位置的问题。
- 改善拖动整理时的插入位置提示、取消操作和边缘自动滚动。
- 优化粘贴导入的位置判定与分类排序切换。
- 完善不同排序模式下的拖放行为，减少误操作导致的排列变化。
- 改善图片导入失败后的继续处理和任务结束提示。
- 修复部分从 Chrome 复制的图片无法正常识别并导入的问题。
