# NekoriEmojy 0.2.5

## 新增与改进

- 分类独立显示排序，HERE / ALL 搜索范围；保持原手动混排数据。
- 可选的一次性自动分类图标；手动图标优先。图库、分类图标、软件图标与快速面板统一使用资源自定义代表帧。
- 父分类标题按本分类与全部后代资源去重计数。
- 真实多帧资源显示可关闭的 ANIM 标记；设置说明使用实际星标和 ANIM 图形。帧选择器新增上一帧、下一帧按钮。
- 图标模式支持独立 Chevron 抽屉折叠，保留分类导航；整卡悬停、内部图标高亮与隐藏选中项的祖先虚线提示相互独立。
- 异常退出后下次启动自动保存有界、脱敏的本地诊断 ZIP，并提醒一次；隐藏启动先生成报告，打开主窗后提醒。不自动上传。

## 已修复问题

- 关闭到托盘后唤醒不再用旧快照覆盖当前图库位置。
- 改善拖动取消区、分类顶部插入线、拖放边缘滚动和粘贴落点；优化侧栏排序切换。
- 非手动排序时静默禁止同分类手动重排，保留跨分类、外部导入及拖出发送。
- 导入队列区分业务结果和原生线程结束，完善失败后继续及恢复收尾。
- 修复有效 Chrome OLE 图片因缺少文件大小声明而被忽略的路径；补充匿名导入阶段与轻量原生故障关联诊断。

## 仍待观察

- R04：历史 Windows 原生访问冲突已调查，根因未确认，暂缓专项实验。
- R12：快速发送退化、R13：特定选择/滚动跳位、R17：长时间运行后的网页导入失败，均保留观察状态；本版不宣称彻底解决。
- Gallery Scroll Ownership 与完整 Library 热切换仅为后续规划，本版未实现。

## 安装与升级

提供 Windows x64 安装版和免安装版，OCR 为独立可选组件。更新前保存设置并正常退出程序（包括托盘）；若文件仍被占用，退出后重试。沿用原配置与 Library，不删除或重置资源库。从 v0.2.2 / v0.2.3 内置更新遇到退出故障时，请正常退出后手动安装。
