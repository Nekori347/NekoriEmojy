- 收紧标题栏、Logo、工具按钮、库标题/数量、Footer 字标与板块间距；窗口三操作共用居中的图标和高亮几何。
- 修正缩略图 Slider 原生输入柄与自绘柄尺寸不一致造成的端部裁切；图片横纵间距 4 DIP，保留虚拟卡池与两侧均衡余量。
- 区分主分栏整高轴、展开 Tag 的带 Chevron 短线、折叠 Tag 的无额外线段；四向索引/添加共用 20 DIP 轨道中心。
- 实时预览作为编辑器即时偏好保存状态，不进入设置 pending；C09 三操作可用为白色实体，不可用为透明线框。
- 剪贴板导入使用透明纯线条组合；主窗与 Quick 的提示改为名称/标签/关键词，并说明实际支持的文件名、所属分类和已有图片文字。
- 所有缓存设置页共享间距和 viewport 样式。
- 最终画面检查补修只读值被压成零宽的问题：版本/构建信息可见，资源库长路径按实际宽度省略并保留完整提示；标签标题直接使用当前主题文字色。

本轮检查、实窗与待体验事项见项目根 `ProjectDocs/CURRENT.md` 的 R01–R17。源码与测试在本 Git 仓库；根 `ProjectDocs`、`Archive`、`DevData` 为项目外层档案，不在该源码仓库内。唯一正常启动入口为根 `Start-Nekori.bat`。
