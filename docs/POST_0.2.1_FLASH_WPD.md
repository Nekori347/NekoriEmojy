### 2026-10-22 第二轮人工反馈：G-12 / G-13

- G-13 折叠热区：原 `ResizeHandle._ear_hover` 只在鼠标事件中刷新。原生探针中鼠标停在热区后缩放窗口，真实指针已落在热区外，缓存仍为真；鼠标焦点也被绘制为相同高亮。`3f63532` 改为绘制时按当前指针与热区几何命中判断，键盘焦点单独显示虚线轮廓。折叠态 chrome 同样按实时指针判断。探针确认缩放后热区外不再 Hover，键盘焦点状态保留。
- G-13 图库横向抖动：隔离数据 90 张资源、60 像素缩略图、1100×760、底部标签，原生探针记录面板高度单向变化，但图库 viewport 曾在 848/836 像素间反复切换，首卡 X 在 42/36 像素间往复。图库画布被设为至少与每帧 viewport 等高，造成滚动范围回写；折叠开始时分隔条也提前释放宽度。`9439bfe` 让画布高度只按内容计算，折叠动画结束后再收窄分隔条。三轮展开／收起的可见帧中，viewport 宽度各自只发生一次有内容依据的单向变化；图库列数、滚动条和画布跟随空间正常调整，未重建资源模型。115 张资源的持续滚动条情形也已采样。
- G-12 连续翻页：实际 `GalleryInterface` 中 81 个分类，连续执行 30 次 Qt 按钮点击，标签几何每次点击后立即变化，中位响应约 6.04 ms、最大约 12.15 ms，未见点击积压、选中分类变化或反复重启选中线动画；同期 90 次绘制、0 次新增尺寸提示计算、3 次选中线目标变化。独立 `TabStrip` 与原生 `QTabBar` 对照也未复现明显停顿。Windows 当前会话未允许探针取得前台焦点，因此系统级实体鼠标连续点击尚未完成；本轮没有足够证据支持继续改动 G-12 源码，用户反馈的 Demo 卡顿仍未解决、待人工复验。
