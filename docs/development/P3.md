# P3 设置与平铺小分类

检查日期：2026-09-14。基于 P2 `0311f1b`，用户规则更新为 `2ce2200`。本阶段为源码实现与隔离验证，正式 ZIP 验收仍在 P6。

## 可观察行为

- 标题栏右侧设置入口打开独立非模态窗口，主图库、当前分类、搜索和选中状态保留。复用原 Fluent 设置卡片。原资源交换、QQ 扫描、TG 下载、关于、诊断与资源库管理入口保留。
- 三个独立布局开关控制多选入口、筛选入口、搜索框的位置；八种组合都检查了实际控件归属。原分类列表与分隔条继续使用，网格为上图标下名称，图标大小、名称显示可调整。主题更新刷新现有卡片样式，不清空多选或重建整页。
- 用户大分类下增加一层平铺小分类，可创建、命名、重命名、排序、折叠、添加/移出成员和删除小分类。没有第三层或嵌套菜单导航。同一图片可关联多个大/小分类，仍只有一份图片实体。
- 删除小分类只去掉该组关系；从大分类移出图片时同步移除其内部小分类关系；大分类重命名/删除有相应事务内触发器。大分类排序保留既有关系，避免“清空再插入”误触发成员删除。
- 搜索临时展开小分类，清空搜索恢复保存的折叠状态。重复出现在不同小分类的同一图片共享选择状态，计数按唯一图片。拖动任意选中卡片带上完整选中集合，包括仍被选中但刚折叠隐藏的成员。
- 拖到大/小分类只添加关联，使用带库和会话标识的拖放载荷；无效/跨库载荷被拒绝。目标高亮在离开/完成后清除。卡片排序继续沿用原全库排序，并支持整组选中图片共同排序。

## D11 / D12：设置语义

采用 Qt 非模态独立窗口；打开时创建内存预览层。设置卡片和原快捷调整共用 ConfigService，预览期间 UI 偏好进入预览层。点击保存后一次性写库内 preferences，窗口继续预览；关闭或取消撤销保存之后的调整。窗口几何等运行状态写入不会把未保存偏好一起泄漏到数据库。

默认值/导入均先预览。导入校验格式、版本、白名单、类型、范围和快捷键冲突；错误文件不覆盖当前配置。导出为偏好 JSON，不带图片、凭据、机器/库路径或本库图标引用；拒绝覆盖库标识、库内 data 和非 JSON 文件。导入/默认值不会切库；存在未保存偏好时，库管理提示先保存或取消。

原有字体设置的“重启后应用”边界保留。开机自启是系统操作，不能通过未保存预览修改注册表。

## 运行时图标与开机自启

- 图标选择器只选择当前库中已有图片，缩略图按可见范围加载；读取静态图或动态图首帧，缩放后设置应用、主窗口、设置窗口图标。库内偏好保存相对文件名，缺失/解码失败回退内置图标。EXE 内嵌图标、托盘图标未被替换。
- 为当前进程设置 NekoriEmojy AppUserModelID。原生 Windows `WM_GETICON` 的小/大图标句柄均随选择更新；这证明窗口图标更新，不能替代最终 EXE 的任务栏外观验收。
- 开机自启使用当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的独立 `NekoriEmojy` 项。仅在用户保存改变后的开关时写入/删除，不在每次启动反复改写。先验证启动程序存在、命令长度符合 Windows 限制；DB 保存失败会尝试恢复原启动项，恢复失败明确提示。
- 启动命令绑定保存时的程序和库路径。程序或库搬迁后，此类机器关联需要重新绑定；可以关闭保存后再开启保存。源码测试没有可用启动器时会拒绝启用，而非登记 Python 开发路径。
- 本阶段没有更改真实启动项，没有重启/注销用户电脑。实际 ZIP 启动器和登录启动留到 P6。

平台依据：[Run / RunOnce](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)、[AppUserModelID](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-setcurrentprocessexplicitappusermodelid)。

## 索引与既有去重能力

设置中提供显式索引检查、补全/重新校验和重复候选查看；后台绑定原库会话，修复不会重写分类、排序、标签或删除图片。完全重复使用持久身份索引。原 pHash/dHash 提取与相似分组算法仍可显式后台运行，只检查库中已登记资源，候选由用户查看处理，不自动删除。支持停止检查；原相似比较仍是两两比较，大库成本随资源数量增加，首导和启动不运行它。

性能定位确认：CategoryGroups.list 中 2000 次 resource() 解析产生 4001 次 Path.resolve，原生路径访问约占 1.44 秒。显示现有数据库成员改为校验 basename 后拼接路径，真正读写边界继续验证实际路径。小分类只预留行几何，复用原分批卡片/缩略图加载；Qt 空行省略自动行距，故明确预留行距，使滚动范围不会随卡片加载增长。实际视口 Resize 负责更新列数。

限制：以上使用合成图片、当前 Windows 和源码环境，不是用户真实大库、浏览器真实手势或最终 EXE。现有卡片模型仍会保留已经滚过的卡片对象，并非完整虚拟列表；访问全库后折叠仍有约 0.3 秒重建成本。大库自然交互、实际任务栏、开机自启、最终包测试继续在 P6 记录。Pillow 对上游 getdata() 有未来版本弃用提示；当前锁定版本正常，不为提示重写已验证哈希算法。
