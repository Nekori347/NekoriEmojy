## 过渡验证

`scripts/iteration1/transition_probe.py --work <新隔离目录>` 从固定上游 Git 对象提取原服务源码，在子进程中操作生成的旧图库，不访问实际安装的 Suzu 或用户 data。

实测 **21 项检查通过**：3 个 PNG/GIF、3 个分类（含空分类）、5 条多分类关系、自定义图片/分类顺序、Tag、最近和偏好只读迁入；源文件 SHA-256 前后不变；小分类不复制图片；整库复制与重新打开保留小分类/折叠/关系；两版资源包互通并幂等导入；原图片不变。

旧 v1 格式不带自定义排序、小分类、最近或设置；原 Suzu 基线导入器忽略空分类，原导出器可能将关键词拆字符。直接只读 data 迁入保留完整关键词。v1 仅支持旧 PNG/GIF 范围，跳过其他格式并记录；不是整库备份。不得声称任意新版 Suzu 格式都已兼容。
