# NekoriEmojy 0.2.5

今回のアップデートでは、カテゴリの閲覧、検索、アニメーション画像の表示を改善しました。また、カテゴリアイコンの自動設定とローカル診断レポート機能を追加し、ドラッグ＆ドロップ、並べ替え、画像の取り込みに関する問題を修正しました。

## 新機能・改善

- **カテゴリの並べ替えと検索**：カテゴリのサイドバーで表示順を個別に切り替えられるようになりました。検索範囲は「現在のカテゴリ（HERE）」と「すべての画像（ALL）」から選択できます。
- **カテゴリアイコンの自動設定**：必要に応じてカテゴリのアイコンを自動設定できます。手動で指定したアイコンが優先されます。
- **サムネイルフレームの統一**：アニメーション画像で選択したフレームを、ギャラリー、カテゴリアイコン、アプリアイコン、クイックパネルにも使用できるようになりました。
- **アニメーション画像の識別**：複数フレームの画像に、無効化できる `ANIM` マークを追加しました。サムネイルのフレーム選択画面には、前後のフレームへ移動するボタンも追加しました。
- **カテゴリ内の画像数表示**：カテゴリの見出しに、配下のサブカテゴリに含まれる画像数も表示し、同じ画像の重複を除いて集計します。
- **アイコンモード**：カテゴリの展開・折りたたみ操作や選択状態の表示を改善し、階層の深いカテゴリも探しやすくしました。
- **ローカル診断レポート**：予期せず終了した場合、次回起動時にローカル診断レポートを自動保存し、通知します。

## 不具合修正

- システムトレイからアプリを再表示した際に、ギャラリーの位置が以前の状態に戻ることがある問題を修正しました。
- 画像をドラッグして整理する際の挿入位置表示、ドラッグのキャンセル、画面端での自動スクロールを改善しました。
- 貼り付けによる取り込み位置の判定と、カテゴリの表示順切り替えを改善しました。
- 表示順ごとのドラッグ＆ドロップ操作を改善し、意図しない並び順の変更を減らしました。
- 画像の取り込みに失敗した後の継続処理と、タスク完了時の通知を改善しました。
- Chrome からコピーした一部の画像を正しく認識・取り込みできない問題を修正しました。
