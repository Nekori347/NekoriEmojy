# NekoriEmojy 0.2.5

## 追加・改善

- カテゴリ別の表示順と HERE / ALL 検索範囲。手動の並び順は維持します。
- 任意の一度だけのカテゴリ自動アイコン。手動指定を優先し、ギャラリー・カテゴリ／アプリアイコン・クイックパネルでリソースの代表フレームを共有します。
- 親カテゴリの見出しは、配下全体の重複を除いたリソース数を表示します。
- 実際の複数フレーム画像に ANIM バッジを表示（無効化可能）。設定説明にも本物の星印と ANIM を使用。フレーム選択に前／次ボタンを追加しました。
- アイコンモードに独立した開閉ボタン、カード全体と子項目それぞれのホバー、折りたたまれた選択項目を示す祖先の破線枠を追加しました。
- 異常終了後の次回起動時に、容量制限・匿名化されたローカル診断 ZIP を作成し、一度通知します。非表示起動ではメイン画面を開くまで通知を延期します。自動送信はしません。

## 修正

- トレイへ閉じる際に現在位置を保存し、古いスナップショットによるギャラリー位置の巻き戻りを修正。
- ドラッグ取消領域、先頭への挿入線、端のスクロール、貼り付け位置を改善。サイドバーの並べ替えを高速化。
- 手動以外の表示順では同一カテゴリ内の手動並べ替えを通知なしで禁止。他カテゴリへの移動、外部取り込み、ドラッグ送信は維持。
- 取り込み結果とネイティブスレッド終了を分離し、失敗後の継続と後処理を改善。
- サイズ宣言のない有効な Chrome OLE 画像を無視する経路を修正。匿名タスク境界と軽量なネイティブ障害関連情報を追加。

## 未解決事項

R04 ネイティブアクセス違反は調査済み・未解決・保留です。R12 送信の退行、R13 選択／スクロールの跳び、R17 長時間稼働後の Web 取り込み失敗は引き続き観察中で、完全解決とはしていません。スクロール所有権と Library 全体のホット切替は計画のみです。

## 更新

Windows x64 インストーラー／ポータブル版を提供します。OCR は任意です。設定を保存し、トレイを含めて通常終了してから更新してください。ファイル使用中は終了後に再試行し、設定と Library は削除しないでください。v0.2.2 / v0.2.3 の更新終了問題では通常終了後に手動インストールしてください。
