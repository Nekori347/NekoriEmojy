# NekoriEmojy 0.2.3

本次更新加入自动备份与恢复、剪贴板搜索、操作音效、新表情标记和通知入口，并改善表情整理、拖放发送与设置体验。

## 新增功能

- **自动备份与完整恢复**：设置备份间隔、保存位置和保留数量，或随时手动备份。可恢复到新的表情库目录，保留分类、标签和排列顺序。
- **剪贴板文本搜索**：设置独立快捷键，用剪贴板文字打开快速面板并搜索；面板已打开时也会更新搜索。
- **操作提示音**：发送、添加、删除、排序和加入分类分别设置声音开关，支持自定义音效、试听和共用音量。
- **新表情标记**：新加入的表情显示星标，查看后自动消除，也可在设置中关闭。
- **通知入口**：标题栏通知按钮可展开尚未清理的通知和任务记录。

## 功能优化

- 相邻表情共享清晰的插入线，整理和拖放更容易定位。
- 新表情默认放在分类前方，批量导入保持顺序；指定插入位置时遵循落点。
- 双击顶部分类标签即可进入对应分类。
- 重新整理设置分组，音效集中到独立页面，相关操作收在同一卡片；数值设置可用图标恢复默认。
- 改善发送结果提示、更新检查布局和诊断资料导出。

## 问题修复

- 修复显示进度或通知时，标题栏部分区域无法拖动。
- 修复单张表情排序后高亮残留，影响其它表情悬停预览。
- 修复拖放重入或延迟处理导致重复提交、投放位置变化。
- 完善窗口空白处接收外部图片的行为，保留分类和明确插入位置的优先级。
- 修复出现未保存提示时，实时预览按钮和文字被挤压、截断。

详见[详细问题修复记录](RELEASE_0.2.3_FIXES.md)。

## 使用与升级

- 提供 Windows x64 安装版和免安装版，普通用户建议使用安装版。升级前保存设置并正常退出程序，包括托盘中的程序；若提示文件仍被占用，正常退出后重试。
- 自动备份和操作音效默认关闭。开启后，备份会在前台繁忙时暂缓。剪贴板搜索快捷键默认留空，需要自行设置。
- 备份保存到表情库之外。恢复生成独立的新表情库，不覆盖正在使用的表情库。
- Windows 10 默认使用不透明背景，可确认兼容性提示后尝试毛玻璃。
- OCR 为可选组件，普通表情管理不要求安装。
