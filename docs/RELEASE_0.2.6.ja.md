# NekoriEmojy 0.2.6

今回のアップデートでは、大量のスタンプを検索・閲覧・整理する際の使い勝手を改善しました。アプリの再起動を必要としないライブラリ切り替えにも対応し、インストールと更新の処理を改善しています。

## 新機能・改善

- **再起動せずにライブラリを切り替え**：設定から別のローカルスタンプライブラリを選択し、そのまま切り替えられるようになりました。
- **クイックパネルの高速化**：初回検索とサムネイルの読み込みを最適化し、大量のスタンプから目的の画像を探しやすくしました。
- **閲覧位置の復元を改善**：カテゴリや検索結果、最近使った項目の切り替え、システムトレイからの復帰時に、スクロール位置をより安定して復元します。
- **アニメーション画像の表示**：代表フレームと切り抜き表示をギャラリーとクイックパネルで同期。ANIM バッジを控えめな半透明スタイルに変更し、マウスを重ねると薄く表示されるようにしました。

## 修正内容

- 他の画面でスタンプを送信したり表示件数を変更したりした後、最近使った項目に古い内容が残ることがある問題を修正。
- 見つからなくなった画像を別のファイルに再関連付けした際、以前の ANIM 表示が残ることがある問題を修正。
- ライブラリ切り替え時と更新ダイアログの状態管理を改善。
- 一部のインストール先でフォルダが二重に作成される問題を修正。インストール・アンインストール時に実行中のプログラムファイルを確認し、不完全な置き換えや削除を防ぐようにしました。
- アプリ内更新時の終了処理、失敗後の復旧と再試行を改善。長時間応答しない場合のローカル診断記録も強化しました。

## ダウンロードと更新

Windows x64 インストーラー版とポータブル版を提供します。文字認識 OCR は引き続き任意のコンポーネントです。

インストーラーで更新する場合は、編集中の内容を保存し、システムトレイから旧バージョンを完全に終了してから実行してください。アプリ内更新では画面の案内に従ってください。

既存の設定と独立したスタンプライブラリはそのまま引き継がれます。
