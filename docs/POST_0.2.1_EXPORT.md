## T-08：真实停止与产物安全（2e2eef9 + d9fd6f4）

- Suzu兼容导出（分类右键／合集入口）及Nekori原生合集导出均通过现有run_exchange_task和现有红色停止入口；仅导出启用可取消参数，导入／迁移／其它任务原契约不变。
- ExchangeWorker使用QThread协作中断请求；服务在目录准备、资源解析、资源／图标写入边界及最终提交前检查。用户请求停止后，当前不可中断的单文件读／解码／写入可能先完成，不强杀线程。
- ExportCancelled独立于错误；调用方显示“导出已停止”，不进入成功分支；失败仍进入原错误提示。取消请求不是确认完成，真正取消只有在服务检查点抛出取消结果后确认。
- 两个现有ZIP写入器共用小型staged_export_path：同目录唯一带点前缀的`.part`临时文件，完整关闭并通过最后取消检查才os.replace发布目标。取消或异常清理临时文件，旧目标保留；无旧目标则不留下正常ZIP。最终原子替换是提交边界，提交完成后的停止请求不回溯已完成的导出。没有第二套任务调度器或强制终止线程。
- 阶段清楚区分读取／解析、资源写入、分类图标与清单。原生格式数量包含资源／分类／清单工作单元，明确标注单位；不是把混合工作量称为表情数。进度任务与最终结果沿原单结果机制收尾，未重复生成完成记录。
