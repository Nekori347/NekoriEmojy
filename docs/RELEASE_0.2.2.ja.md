# NekoriEmojy 0.2.2

今回のアップデートでは、スタンプの整理、ドラッグ＆ドロップ、一括インポート、日常操作を改善し、0.2.1 の公開後に報告された複数の問題を修正しました。

## 新機能・改善点

### スタンプの整理
- **選択操作の統一**：スタンプとカテゴリノードの選択を統一し、Ctrl／Shift による複数選択や一括操作を改善しました。
- **カテゴリ見出しの固定表示**：ギャラリーをスクロールしても、現在のカテゴリ見出しを上部に表示できます。
- **ドラッグ＆ドロップの改善**：スタンプやカテゴリノードを上部のカテゴリタブへ移動できるようになり、ドロップをキャンセルする領域も追加しました。
- **ごみ箱へのドラッグ保護**：メインギャラリーからのドラッグには元ファイルとは別のコピーを使用し、ライブラリから削除する前に確認します。

### インポートとタスク管理
- **グローバルインポートショートカット**：画像をコピーした後、`Ctrl + Alt + V` でインポートできます。キーの変更や無効化にも対応しています。
- **重複ファイルの一括処理**：一括インポート時の重複スタンプをまとめて確認・処理できます。
- **中断したタスクの再開**：対応するローカルインポートや OCR タスクが中断した場合、次回起動時に再開・保留・破棄を選択できます。完了済みの処理を無条件に繰り返すことはありません。
- 進捗表示、ギャラリーの段階的な更新、エクスポートの安全な停止処理を改善しました。

### 画面と操作性
- タスクの進捗と一時通知を重ねて表示する従来の方式を維持しつつ、通知の展開・消去・一時停止・残り時間表示を改善しました。
- 並び順、設定、インポート／エクスポート、各ツールの案内文を見直し、簡体字中国語・繁体字中国語・英語・日本語の表示を改善しました。
- UI アニメーションとウィンドウのアクリル効果を個別に設定できるようになりました。
- 起動時のバックグラウンド更新確認に対応しました。更新を無断でインストールすることはありません。
- アプリを再度起動した際、実行中のウィンドウを呼び出すように改善しました。
- アプリメニューと「このアプリについて」に**フィードバック・ご提案**を追加しました。環境情報はユーザーの操作によってのみコピーされます。

### パフォーマンス・安全性・安定性
- 一部のギャラリー検索、カテゴリ索引、メニュー生成、一括カテゴリ操作で重複処理を削減しました。
- リソースパッケージ内の参照パス、アーカイブ内容、画像ダウンロードサイズの検証を強化しました。
- Telegram の標準接続設定が無効になった際の復旧処理と、カスタム認証情報・プロキシ通信の保護を改善しました。
- 診断ログの保存範囲と、ユーザー操作によるエクスポートを改善しました。ライブラリや診断ファイルを自動送信することはありません。

## ダウンロード・更新

Windows x64 向けのインストーラー版とポータブル版を提供します。OCR は引き続き任意の追加コンポーネントです。

更新前にスタンプライブラリと設定をバックアップすることをおすすめします。ユーザーデータはアプリ本体とは別の場所に保存される場合があるため、更新時にデータフォルダを削除しないでください。

不具合報告や機能提案は、アプリ内のフィードバック機能または [GitHub Issues](https://github.com/Nekori347/NekoriEmojy/issues) から送信できます。

- **OCR は任意導入**で、必要に応じてアプリの設定からインストールできます。通常は OCR の ZIP や JSON を先に手動でダウンロードする必要はなく、基本的なスタンプ管理に OCR は不要です。
- `BUILD_INFO.json`、`RELEASE_INFO.json`、`NekoriOCR-win-x64-1.metadata.json` は、診断やコンポーネントのインストール処理で使うビルド・リリース・OCR コンポーネントのメタデータです。アプリのインストーラーではありません。
- `SHA256SUMS.txt` は、ダウンロードしたファイルの SHA-256 チェックサムを照合するためのものです。
- `NekoriEmojy-0.2.2-Source.zip` と GitHub が自動で用意する Source code ZIP / tar.gz は、コードを読んだり自分でビルドしたりする方向けです。通常の利用には必要ありません。
