# NekoriEmojy 0.2.3

自動バックアップと復元、クリップボード検索、操作音、新しい絵文字のマーク、通知ボタンを追加しました。絵文字の整理、ドラッグ＆ドロップ、送信、設定画面も改善しています。

## 新機能

- **自動バックアップと完全な復元**：間隔、保存先、保持数を設定でき、手動でも開始できます。分類、タグ、並び順を保ったまま、新しいライブラリに復元できます。
- **クリップボードのテキスト検索**：専用ショートカットでクイックパネルを開き、コピーした文字を検索できます。パネルが開いている場合も検索内容を更新します。
- **操作音**：送信、追加、削除、並べ替え、分類への追加を個別にオン・オフできます。音声ファイルの選択、試聴、共通の音量調整に対応します。
- **新しい絵文字のマーク**：追加した絵文字に星を表示し、確認すると自動的に消えます。設定から無効にすることもできます。
- **通知ボタン**：タイトルバーから、消去していない通知やタスクの記録を開けます。

## 改善

- 隣り合う絵文字が挿入位置の線を共有し、ドロップ位置を確認しやすくなりました。
- 新しい絵文字は標準で分類の先頭に追加されます。一括追加の順番を保ち、挿入位置を指定した場合はその位置に配置します。
- 上部の分類タブをダブルクリックすると、その分類に移動できます。
- 設定のグループを整理しました。操作音を専用ページにまとめ、関連する操作を同じカードに配置しました。数値設定には初期値に戻すアイコンがあります。
- 送信結果の案内、更新確認の表示、診断データの書き出しを改善しました。

## 修正

- 進捗や通知の表示中に、タイトルバーの一部をドラッグできなくなる問題を修正しました。
- 1枚の絵文字を並べ替えた後に強調表示が残り、他のプレビューを妨げる問題を修正しました。
- ドラッグ＆ドロップの重複処理や、遅延処理による配置位置の変化を修正しました。
- 分類や挿入位置の指定を優先しながら、ウィンドウの空白部分でも外部画像を受け取れるようにしました。
- 未保存の変更があるときに、ライブプレビューのボタンと案内文が切れる問題を修正しました。

[詳しい修正記録（簡体字中国語）](RELEASE_0.2.3_FIXES.md)もご覧ください。

## 使用とアップグレード

- Windows x64のインストーラー版とポータブル版を用意しています。通常はインストーラー版をおすすめします。更新前に設定を保存し、トレイ内のものも含めてアプリを正常に終了してください。ファイルの使用中と表示された場合は、終了してから再試行してください。
- 自動バックアップと操作音は初期状態では無効です。バックアップは操作中に一時停止します。クリップボード検索のショートカットは任意で設定してください。
- バックアップはライブラリの外に保存してください。復元先には別の新しいライブラリを作成し、使用中のものを上書きしません。
- Windows 10では不透明な背景を標準にします。互換性の注意を確認した後にアクリル効果を有効にできます。
- OCRは任意の追加コンポーネントです。通常の絵文字管理には必要ありません。
