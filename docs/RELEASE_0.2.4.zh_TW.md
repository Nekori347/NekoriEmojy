# NekoriEmojy 0.2.4

## v0.2.4 修復更新

- 修復內建更新時程式可能無法正常結束，導致更新逾時失敗的問題。
- 改善更新工作的結束協調、異常回饋及重試流程。
- 修復更新說明中的連結無法點擊開啟的問題。

**從 v0.2.2 / v0.2.3 升級**：若內建更新停在準備重新啟動，請從本次發佈頁下載安裝版，儲存設定並正常結束程式（包含系統匣）後手動安裝。下載新版本無法修復舊程式本身的結束流程。請勿刪除表情庫；安裝版會沿用原安裝位置與資料。

以下同時保留 v0.2.3 的功能更新。

本次更新加入自動備份與還原、剪貼簿搜尋、操作音效、新表情標記與通知入口，並改善表情整理、拖放傳送和設定體驗。

## 新增功能

- **自動備份與完整還原**：設定備份間隔、儲存位置及保留數量，也可手動備份。還原至新的表情庫目錄，保留分類、標籤與排列順序。
- **剪貼簿文字搜尋**：設定獨立快捷鍵，使用剪貼簿文字開啟快速面板並搜尋；面板已開啟時也會更新搜尋。
- **操作提示音**：傳送、新增、刪除、排序及加入分類可個別開關音效，支援自訂音效、試聽與共用音量。
- **新表情標記**：新加入的表情顯示星號，查看後自動消除，也可在設定中關閉。
- **通知入口**：標題列通知按鈕可展開尚未清除的通知與工作紀錄。

## 功能改善

- 相鄰表情共用清楚的插入線，方便準確拖放。
- 新表情預設放在分類最前方，批次匯入保留順序；指定插入位置時依照落點排列。
- 按兩下頂部分類分頁即可進入對應分類。
- 重新整理設定分組，音效集中於獨立頁面，相關操作整合於同一卡片；數值設定可透過圖示還原預設值。
- 改善傳送結果提示、更新檢查版面及診斷資料匯出。

## 問題修正

- 修正顯示進度或通知時標題列部分區域無法拖動。
- 修正單張表情排序後反白殘留，影響其他表情的懸停預覽。
- 修正拖放重入或延後處理造成重複提交、落點改變。
- 完善視窗空白處接收外部圖片，保留分類與明確插入位置的優先順序。
- 修正出現未儲存提示時，即時預覽按鈕及文字被擠壓、截斷。

詳見[詳細問題修正紀錄（簡體中文）](RELEASE_0.2.4_FIXES.md)。

## 使用與升級

- 提供 Windows x64 安裝版與免安裝版，一般使用者建議使用安裝版。升級前請儲存設定並正常結束程式，包括系統匣中的程式；若提示檔案仍被占用，正常結束後重試。
- 自動備份與操作音效預設關閉。啟用後，備份會在前台忙碌時暫緩。剪貼簿搜尋快捷鍵預設空白，需自行設定。
- 備份請存放於表情庫之外。還原會建立獨立的新表情庫，不覆蓋使用中的表情庫。
- Windows 10 預設採用不透明背景，可確認相容性提示後嘗試毛玻璃。
- OCR 為選用元件，日常表情管理不必安裝。
