# NekoriEmojy 0.2.5

## 新增與改善

- 分類獨立顯示排序與 HERE / ALL 搜尋範圍，保留手動混排資料。
- 可選的一次性自動分類圖示，手動圖示優先；圖庫、分類／軟體圖示及快速面板共用資源自訂代表影格。
- 父分類標題依本分類及所有後代資源去重計數。
- 真正多影格動畫顯示可關閉的 ANIM 標記；設定說明使用實際星標與 ANIM 圖形。影格選擇器新增上一格／下一格按鈕。
- 圖示模式提供獨立 Chevron 抽屜折疊、整卡懸停、子項獨立高亮，以及隱藏選取項的祖先虛線提示。
- 異常結束後下次啟動自動儲存有容量限制、去識別化的本機診斷 ZIP，並提醒一次。隱藏啟動會等開啟主視窗才提醒，不會自動上傳。

## 修正

- 關閉至系統匣後恢復，不再以舊快照覆蓋目前圖庫位置。
- 改善拖曳取消區、側欄頂部插入線、邊緣捲動與貼上落點；加快側欄排序切換。
- 非手動排序時靜默禁止同分類手動重排，保留跨分類拖放、外部匯入與拖出傳送。
- 匯入佇列區分業務結果與原生執行緒結束，改善失敗恢復與收尾。
- 修正 Chrome OLE 有效圖片在未宣告檔案大小時被忽略的路徑；補充匿名匯入生命週期與輕量原生故障關聯診斷。

## 尚待觀察

R04 原生存取違規已調查、未解決並暫緩。R12 傳送退化、R13 選取／捲動跳位、R17 長時間執行後網頁匯入失敗仍保留觀察，未宣稱完全修復。捲動所有權架構與整個 Library 熱切換僅為規劃，未實作。

## 升級

提供 Windows x64 安裝版與免安裝版，OCR 為選用元件。更新前儲存設定並正常結束（包括系統匣）；檔案被占用時，結束後重試。保留原設定與資源庫。v0.2.2 / v0.2.3 內建更新若無法結束程式，請正常退出後手動安裝。
