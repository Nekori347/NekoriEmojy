# NekoriEmojy 0.2.5

本次更新改善了分類瀏覽、搜尋及動態圖片顯示，新增自動分類圖示與本機故障報告，並修正多項拖曳、排序及圖片匯入問題。

## 新增功能與改善

- **分類排序與搜尋**：分類欄支援獨立切換顯示排序方式。搜尋範圍可在「目前分類（HERE）」與「全部資源（ALL）」之間切換。
- **自動分類圖示**：支援依需求自動為分類選取圖示，優先保留已手動設定的圖示。
- **統一圖片代表影格**：動態圖片選定的代表影格現在可用於圖庫、分類圖示、軟體圖示及快速面板。
- **動態圖片標記**：為多影格圖片增加可關閉的 `ANIM` 標記。縮圖影格選擇器新增上一格、下一格按鈕。
- **分類數量統計**：分類標題現在會統計下層子分類中的圖片，並自動合併重複計數。
- **圖示模式**：改善分類展開、收合及選取狀態的顯示，讓多層分類瀏覽更加直覺。
- **本機故障報告**：程式意外結束後，下次啟動會自動儲存本機故障報告，並提醒使用者查看。

## 問題修正

- 修正從系統匣重新開啟程式時，圖庫可能跳回舊位置的問題。
- 改善拖曳整理時的插入位置提示、取消操作及邊緣自動捲動。
- 改善貼上匯入的位置判定與分類排序切換。
- 完善不同排序模式下的拖曳行為，減少誤操作造成的排列變化。
- 改善圖片匯入失敗後的繼續處理及工作結束提示。
- 修正部分從 Chrome 複製的圖片無法正常辨識及匯入的問題。
