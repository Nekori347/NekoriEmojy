# NekoriEmojy 0.2.4 · 详细问题修复记录

## v0.2.4：内置更新

- 区分更新窗口的用户关闭保护与应用主动退出，避免更新窗口自身否决退出，导致独立更新器等待超时。
- 后台任务协作结束，有界等待且不阻塞界面；未保存设置仍可拒绝升级，内容不丢失。
- 失败或取消保留已验证的更新包；交接状态和取消结果可回传，重试仍受同目录安装锁保护。
- 更新说明中的 HTTPS 链接交由系统浏览器打开，不执行不安全协议；保留 Markdown、滚动和文本选择。

旧版已安装的退出代码不会因下载目标包而改变。v0.2.2 / v0.2.3 内置更新退出失败时，请正常退出后使用官方安装版手动升级一次。

以下为同样包含在本版中的 v0.2.3 修复。

## 拖放与排列

- 修复一次拖动在事件重入或延迟处理时被重复提交的问题。
- 修复松手后继续移动鼠标可能影响排序目的地的问题，按实际接受投放的位置完成排列。
- 修复单张表情排序后原卡片高亮残留、其它卡片必须点击空白后才能恢复预览的问题。取消拖动后也可继续正常悬停。
- 保留 Ctrl/Shift 多选，批量排序后不会因单图状态清理而丢失有意保留的选择。
- 相邻表情使用同一逻辑插入位置，改善间隙落点和指示线的一致性；相关分类间隙历史记录见 [#18](https://github.com/Nekori347/NekoriEmojy/issues/18)。
- 修复向已手动排列的分类添加新表情时默认位置不在前方的问题，批量导入保持内部顺序。

## 发送与外部交付

- 改善目标失效、复制失败和仅复制结果的反馈，避免操作没有可见提示。
- 区分拖出所用副本与图库原件，避免跨目标经过时重复完成操作；拖放交付不作为主动发送的成功结果。
- 窗口可接收的空白区域也能导入外部图片，明确分类和插入位置仍优先，自身资源拖入空白不会误作新文件导入。

## 标题栏、通知与工具

- 修复显示通知或任务进度时，标题栏非交互区域无法正常拖动的问题，操作按钮仍可点击。
- 通知按钮可打开单条未清理记录，不再要求多条通知才可展开；保留原通知列表与清理行为。
- 改善最大化时顶部白条、相似表情分组分页、更新检查布局与诊断资料导出显示。

## 设置与音效

- 修复未保存提示与实时预览按钮争用空间造成的截断，长语言文本按可用空间排布。
- 音效相关开关、来源和操作收在同一卡片；试听与实际事件使用共用音量，关闭业务音效时仍可试听。
- 修复拖放结束后的鼠标状态影响其它卡片交互的问题，保留多选与插入指示能力。
