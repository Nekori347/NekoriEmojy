# NekoriEmojy 0.2.2

本地表情管理工具。启动当前目录中的 `NekoriEmojy.exe`。请不要覆盖原 Suzu 安装目录。

首次启动按提示选择或连接表情库。配置默认保存在 `%LOCALAPPDATA%\NekoriEmojy`，推荐表情库位置为用户 Pictures 下的 `NekoriEmojy Library`。已有自定义表情库路径继续使用；移动目录后在恢复窗口重新定位，不要删除原数据。

正式独立版已包含运行环境，无需预先安装 Python。配置保存在用户可写目录。开发轻量版会按需联网准备环境。文字识别是独立可选组件，基础程序不包含OCR运行时；图片识别只在本地进行。文字识别 OCR 仍为可选组件，普通表情管理不需要预先安装。

本目录只包含程序和必需资源，不包含个人表情、测试表情库或开发资料。更新/重装前请保留配置和表情库；程序目录与表情库是不同概念。
