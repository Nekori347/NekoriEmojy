# T-06 / #34：导入与 OCR 中断恢复

2026-10-24；接管 e44f468，源码 c374c9a。已实现、定向机器验证，待固定 Demo 人工验收。只处理 T-06，不修改窗口宿主及 T-07。

## 原有结构与提交边界

- ImportQueue 的请求、原任务 ID、等待集中重复决策原先只在内存。ImportThread 复用 ResourceImporter/现有编解码与去重；目录递归会复用同名分类或创建子分类。
- 原文件保存先于资源注册，注册与分类关联又分别提交。进度 Signal 不是可据以恢复的持久结果。
- OcrService 已存最近任务摘要，并将 running 改为 interrupted；一般任务没有可靠的待处理资源清单，原 resume_ids 只覆盖部分主动取消的强制全库识别。已有 source_stamp、OCR_VERSION、revision compare-and-set 继续使用。
- delete_after 的文件删除/失败移动，keep 的 force_new 与 replace 都不能盲目重放。正常任务的这些既有行为保持原样。

## 此次实现

沿用当前 Library 的 index.sqlite3，增加一张 task_checkpoints 表。它只存任务头、来源快照、分类身份/位置锚点、未完成单元和小型提交凭据，不是第二套任务数据库或执行队列；不含图片字节或 OCR 文本副本，不进入诊断 ZIP/日志预算。

### 文件及目录导入

1. 入队先存稳定 ID 与来源/目标；worker 开始时一次性建立文件/目录清单，记录来源大小、mtime、设备及文件身份。GUI 不递归扫描来源。扫描事务未提交前不会执行导入；扫描完成后新增的目录内容不加入旧批次。
2. ImportThread 沿原流水线按清单处理，仍只用原 ResourceImporter/存储/集中去重。分类节点创建或复用/定位与节点凭据一同提交，重开不另建同名层级。
3. 资源注册、分类成员关系及文件完成凭据放在同一目录事务。成功凭据先于 UI 进度。已提交单元不重放、不重排；待处理单元按稳定锚点的当前位置插入，锚点消失则按原追加规则回退。
4. 规范化文件/特征已落盘但尚未进入目录时，恢复借用现有去重能力接纳这些字节，不把没有目录记录的残留文件当成已存在资源冲突。仍不能把凭据缺失解释为已经完成。
5. 尚未决策的重复项重新进入原 T-09 集中比较窗口，不能自动代选。keep/replace 在副作用前标为不确定，成功接纳时同事务完成；中间崩溃则禁止自动重放。

### OCR

1. 在原 OcrService 中保存原任务的资源清单、初始修订与原触发语义；worker 在推理前记录实际 source_stamp。全库请求的展开仍在原 worker，展开清单与替换扫描标记原子提交；小范围恢复不扫描全库。
2. 识别结果与本资源完成凭据同事务提交。因此即使结果提交后、摘要更新前强制结束，恢复也不会重新识别该已完成单元，包括原强制识别任务。
3. 只排入待处理 ID；资源删除、来源身份或修订改变、人工修订会保留当前结果并记为跳过，不用旧任务覆盖新内容。恢复不授权覆写人工文本；需要时由用户另行明确重新识别。
4. 缺失资源文件进入等待来源，检查点保留；重新连接后由用户继续。OCR 模型不可用时沿原安装提示，不自动下载。
5. 自动 OCR 仍沿导入原 ID，运行/等待/完成更新同一反馈记录。历史已完成或主动取消的 OCR 摘要不会在新会话重新弹成恢复任务。

## 恢复入口与明确边界

启动从 Library 读取未结束任务，不查来源磁盘、不启动 worker、不弹强制模态框。现有任务通知提供恢复入口；非模态选项明确区分继续、暂不继续、放弃。暂不继续保留记录；关闭通知也不删除记录，重启仍可发现。放弃仅删除恢复记录，已提交数据不变。

可以继续：本轮机制创建的本地文件/目录导入、具有可靠资源清单的手动/自动 OCR。主动取消不在重启时恢复，部分失败保持真实计数。来源暂不可用保留等待状态；来源明显改变或目标分类缺失不静默回退根层。

明确不可安全自动继续：删除来源的导入、URL/剪贴板内存图像、迁移等 operation 回调、keep/replace 提交结果不明的单元，以及升级前没有清单的历史 OCR 任务。通知说明原因并禁用继续，允许保留或放弃，再经原入口重新提供来源/核对。没有假继续按钮，也没有扩展迁移恢复或新的下载框架。

这不是任意指令级文件系统回滚；底层写文件中断的未登记碎片不作为可靠资源结果，不盲删来源或现存文件。本轮不建设全新存储事务引擎。

## 存储与性能

- 每个任务/来源单元只存必要元数据，空间随仍未完成批次规模增长；完成/主动取消/明确放弃即清理凭据，不累积历史清单。未完成任务不因年龄被静默删除；现有 OCR 摘要只保留近期 20 项及仍待处理的任务。
- 本地 80 文件清单实测 81 行、23,936 字节 UTF-8 元数据；完成/放弃后删除，不另存资源副本，也不占 T-07 的 2.5MiB 日志预算。
- 复用资源提交连接写导入完成凭据，不为每个导入文件额外多开检查点连接或全库查询。目录身份预取一次；OCR 单元查询按任务 ID/资源 ID 索引，不每次重读整批清单。
- 80 张隔离 96×96 图片的单次前后同流水线对照：不启用恢复 81.119s，启用恢复 76.621s；Qt 心跳峰值分别 1067.37/31.52ms。顺序、缓存及当前桌面负载影响结果，不宣称性能提升或所有大库流畅，仅未观察到检查点造成额外总耗时。结束后无剩余检查点。
