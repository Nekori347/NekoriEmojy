# NekoriEmojy

Windows 向けのローカルスタンプ管理ツールです。

スタンプの収集、整理、検索、送信に使えます。カテゴリ、タグ、検索に加え、普段の操作をもう少し直接行えるようにしています。表示されているスタンプをドラッグして整理し、よく使う操作にはいくつものメニューを経由せずにアクセスできることを目指しています。

<a id="organization"></a>
## 🗂️ カテゴリ・サブカテゴリ・ノード

カテゴリは、左側に並ぶフォルダだけではありません。NekoriEmojy では共通のカテゴリ階層を使い、現在の位置に応じて、異なる階層を**左側のカテゴリバー、上部のカテゴリタブ、スタンプのコンテンツ領域**に表示します。大きなカテゴリからサブカテゴリに進むことも、現在のビューでさらに下の階層の内容を直接整理することもできます。

**カテゴリノードは通常のスタンプと混在させて並べられます。** 数枚のスタンプの後にノードを置き、その後に別のスタンプを続けることができます。ノード自体の展開、折りたたみ、並べ替えも可能です。リストの先頭にしか置けないフォルダへの入口でも、内容と関係のない区切り線でもありません。

大量のスタンプをキャラクター、用途、好みの分類方法でいくつかのまとまりに分けたいときに便利です。必要なときだけ展開し、普段は折りたたんでおけます。小さなグループごとに独立した閲覧ページを設ける必要もありません。

</p>

<p align="center">

> **カテゴリ、カテゴリノード、タグはそれぞれ異なります。** カテゴリとノードは同じ階層構造に属します。上部のカテゴリタブは現在の位置でカテゴリビューを切り替えるためのもので、スタンプのタグは別の関連付け・検索手段です。1枚のスタンプを複数のカテゴリに関連付けても、画像ファイルを重複保存する必要はありません。

<a id="drag-and-sort"></a>
## ↕️ ドラッグと自由な並べ替え

整理は、できるだけスタンプが表示されている場所で直接行えるようにしています。

- 1枚のスタンプをドラッグして順番を変えるほか、**複数選択してまとめてドラッグし、並べ替える**こともできます。
- 対応するカテゴリやノードの対象領域にスタンプをドラッグし、それぞれの操作に応じて整理できます。
- カテゴリビュー内でカテゴリノードの位置を変え、ノードと通常のスタンプを好みの順序で混在させられます。
- 専用の管理ダイアログだけに頼らず、必要に応じてカテゴリの階層や同じ階層内の順序を調整できます。
- タグパネルや一括操作で、1枚ずつ同じ設定を繰り返す手間を減らせます。

ショートカットやボタンからの貼り付けに加え、コンテンツ領域の指定した位置で右クリックして貼り付けることで、整理中の位置に新しいスタンプを直接追加できます。

次のデモでは、単に「ファイルをフォルダに入れる」のではなく、**同じコンテンツビュー内で複数のスタンプと折りたたみ可能なノードを動かし、閲覧順序を直接変える**操作を示しています。

<a id="find-and-preview"></a>
## 🔎 検索とプレビュー

スタンプが増えるほど、保存するだけでなく、使いたい1枚をすぐに見分けて探せることが大切になります。

- **名前とタグで検索**：登録済みの名前、タグ、キーワードで絞り込みます。
- **文字認識（OCR）**：必要に応じてローカルコンポーネントを導入し、スタンプ内の文字を認識して検索に利用できます。認識した文字と手動のタグは別々に保存されます。
- **最近使ったスタンプ**：メインパネルやクイックパネルから、最近使ったものを見つけ直せます。
- **アニメーションのプレビュー**：GIF などの動くスタンプを実際の動きで確認できます。
- **GIF サムネイルの表示フレームを指定**：元のアニメーションを変更せず、一覧で見分けやすいフレームをサムネイルにできます。

特に最後の機能は、GIF の標準サムネイルが空白や動作途中のフレームになっている場合に役立ちます。見分けやすい場面を選ぶことで、保存したスタンプを一覧で見失いにくくなります。

<a id="quick-use"></a>
## ⚡ すばやく使う

毎回、管理画面全体を開く必要はありません。

- **クリック送信**：対応する送信先ウィンドウに対して、スタンプをクリックすると送信処理を行います。毎回手動でウィンドウを切り替えて貼り付ける必要はありません。
- **ドラッグ送信**：送信先アプリの必要な位置にスタンプをドラッグします。
- **貼り付けでインポート**：画像をコピーし、画面のボタンからライブラリに追加します。
- **クイックパネル**：ショートカットでコンパクトなパネルを呼び出し、スタンプの検索や最近使ったものの選択ができます。

メインギャラリーでのシングルクリックは、スタンプの選択または直接送信のどちらにするか、使い方に合わせて設定できます。

送信は、送信先アプリが画像を受け取る方法や Windows のウィンドウ状態にも左右されます。対応しない送信先では、通常のコピー＆ペーストなどを利用してください。

**静止画スタンプを GIF として送信**

チャットアプリによっては、通常の静止画が大きな原寸画像として表示されることがあります。

NekoriEmojy の「送信時に静止画を GIF に変換」オプションでは、送信時に静止画スタンプを一時的に単一フレームの GIF に変換し、スタンプに適した形で表示されるよう試みます。

静止画をアニメーションにする機能ではなく、ライブラリに保存した元の画像も変更しません。実際の表示は、画像を受け取るチャットアプリによって異なります。

## 🎨 外観とカスタマイズ

画面の構成も、自分の使い方に合わせて調整できます。

- カテゴリバーの表示モードや、サブカテゴリとコンテンツ領域の閲覧方法。
- 上部のカテゴリタブ、折りたたみ可能なノード、タグパネルの組み合わせ。
- タグパネルの位置・展開状態、スタンプのサムネイルサイズなどのレイアウト設定。
- ライト／ダークテーマとウィンドウの外観設定。
- ウィンドウ、タスクバー、システムトレイでアプリを識別するための**アプリアイコンの変更**。
- **i18n による多言語 UI**と、カスタマイズ可能なショートカットキー。

メインパネルは整理と管理に、クイックパネルは日常の検索と送信をコンパクトに行うために使えます。両方で同じスタンプデータを共有します。

### テーマとアクセントカラー

NekoriEmojy はライト、ダーク、システム設定に合わせる外観モードに対応し、テーマのアクセントカラーも変更できます。

アクセントカラーを調整すると、画面に変更がリアルタイムで反映されます。毎回保存してメインウィンドウに戻らなくても結果を確認できます。気に入らなければキャンセルしたり変更を破棄したりでき、確認してから保存できます。

ライトテーマ、ダークテーマのどちらでも、異なるアクセントカラーを組み合わせられます。

<a id="import-and-data"></a>
## 📦 インポートとデータ管理

日常の収集・整理に加え、ライブラリを管理するためのツールもあります。

- ローカルのファイル、フォルダ、クリップボードから画像をインポート。
- 整理や共有のためにスタンプコレクションをインポート・エクスポート。
- 複数選択による管理、カテゴリとの関連付けの変更、並べ替え。
- QQ、Telegram などを対象としたインポートツールと、SuzuEmojy の既存スタンプデータを移行する手段。
- 任意導入の文字認識コンポーネントのインストールとタスク管理。
- 類似画像の検索：ライブラリ内の似た画像をスキャンし、まとめてプレビューしてから、整理するものを自分で選択。

利用条件はデータの出所や形式によって異なる場合があります。対応していない内容については、アプリ内の実際の案内に従ってください。

### 独立したスタンプライブラリのディレクトリ

NekoriEmojy のスタンプライブラリは、プログラムと同じフォルダに置く必要はありません。

別のドライブや画像収集専用のディレクトリなど、保存先を自分で選べます。インポートしたスタンプファイル、カテゴリ情報、リソースインデックスは選択したライブラリに保存され、アプリの個人設定は別に保存されます。

インストール先の変更や再インストールをしても、それだけでコレクション全体を整理し直す必要はありません。元のライブラリが完全な状態で残っていれば、設定から再接続できます。

別のライブラリを選択した場合、切り替えるには設定を保存してアプリを再起動する必要があります。また、インポート時は画像をコピーまたは変換して選択したライブラリに保存します。元の参照元ファイルをその場で直接管理する方式ではありません。

ライブラリだけをバックアップしたり、移行したり、適した場所に保存したりしやすくなります。

### リソースパッケージ・共有・バックアップ

整理したスタンプライブラリは、エクスポートして保存することもできます。

NekoriEmojy には、用途の異なるいくつかのデータ出力方法があります。

**Nekori ネイティブリソースパッケージ**

現在のライブラリを ZIP リソースパッケージとしてエクスポートできます。スタンプ画像に加え、カテゴリとサブカテゴリの構造、カテゴリアイコン、ノードとスタンプの並び順、タグ、文字認識結果、GIF のサムネイルフレーム選択など、記録済みの関連情報を保存します。

ネイティブリソースパッケージは、Nekori で整理した結果を保存・移動する用途に適しています。インポート時は現在のライブラリのデータと統合され、既存のライブラリ全体をそのまま上書きするものではありません。

<p align="center">
  <img src="docs/media/nekori-package.png" alt="Nekori ネイティブリソースパッケージのインポート・エクスポートと実際の ZIP ファイル" width="75%">
</p>

**互換共有パッケージ**

Suzu 形式のスタンプ共有パッケージもエクスポートできます。ライブラリ全体、または指定したカテゴリを出力し、互換形式で画像を整理・共有できます。

大きな共有パッケージは、容量に応じて複数の圧縮ファイルに分割して保存・転送できます。

パッケージ形式によって保存できる情報の範囲は異なります。Nekori のノードとスタンプの混在した並び順など、整理結果を保つことが主な目的なら、Nekori ネイティブリソースパッケージを優先してください。

**設定ファイル**

アプリの設定だけを JSON ファイルとしてエクスポートし、必要なときに再インポートできます。

スタンプデータの整理とは別に、画面や操作に関する個人設定を保存できます。

<p align="center">
  <img src="docs/media/data-export.png" alt="リソースパッケージ、互換共有パッケージ、設定ファイルのエクスポート" width="80%">
</p>

**データ全体のバックアップ**

スタンプライブラリのディレクトリとアプリの設定は、別々に保存されます。全体をバックアップする場合は、共有パッケージだけでなく、実際のライブラリディレクトリと必要なアプリデータも別途保存してください。

リソースパッケージは整理結果のエクスポート、移行、共有に向き、ディレクトリ全体のバックアップは元のライブラリの状態を保持する用途に向いています。必要に応じて併用できます。

### SuzuEmojy からの移行

以前 SuzuEmojy を使っていた場合は、NekoriEmojy の移行ツールで既存のスタンプコレクションを引き続き利用できます。

現在、次の2種類の取り込み元に対応しています。

- **既存の SuzuEmojy データを読み込む：** この PC で実行中の SuzuEmojy インスタンスを探し、その既存データを読み取って Nekori に移行します。
- **Suzu 共有パッケージをインポートする：** 以前エクスポートしたスタンプリソースの圧縮ファイルを選択して取り込みます。

移行時は、読み取れる画像、カテゴリ、サブカテゴリ、カテゴリアイコン、タグのキーワード、並び順の情報を可能な限り引き継ぎます。元の Suzu データは変更されず、移行のために先に旧アプリを削除する必要もありません。

データの出所や形式によって違いがあるため、実際に引き継げる情報は元データに含まれる内容によります。移行後はカテゴリ、スタンプ数、並び順を確認してください。

この互換機能は、アプリを変更する際の再インポートや整理し直しの手間を減らすことを主な目的としています。

<a id="download"></a>
## ダウンロードと使い方

最新版は [GitHub Releases](https://github.com/Nekori347/NekoriEmojy/releases/tag/v0.2.1) から入手できます。

現在、Windows x64 向けに2つの利用方法を用意しています。

- **インストーラー版**：インストーラーを実行してインストールします。
- **ポータブル版**：解凍後、同梱の説明に従って起動します。インストーラーを使いたくない場合に適しています。

文字認識は**任意導入のコンポーネント**です。OCR を使わない場合、通常の整理、名前・タグによる検索、送信のために認識コンポーネントを先に入れる必要はありません。画像内の文字を認識したくなったときに、アプリの設定から案内に従って導入できます。

ショートカットキーや一部の画面動作は、設定で確認・変更できます。

**更新とデータ：** スタンプライブラリと個人設定は異なる場所に保存されている場合があります。更新やインストール方法の変更前には、両方のバックアップを推奨します。アンインストールやプログラムディレクトリの削除と、ユーザーデータの削除を同一視しないでください。詳細は該当バージョンのリリースノートを参照してください。

<a id="development"></a>
## 開発について

NekoriEmojy は、個人で開発・保守している **Vibe Coding プロジェクト**です。機能の計画、UI デザイン、操作の調整は主に個人的な利用ニーズに基づいており、コードの多くは AI の支援を受けて作成・修正を繰り返しています。

まだ見つかっていない不具合が残っている可能性があります。特に、アプリごとのドラッグ・送信の違いや、Windows 環境による動作差などが考えられます。再現できる不具合の報告や改善案は [GitHub Issues](https://github.com/Nekori347/NekoriEmojy/issues) にお寄せください。
