# 已暂停的 OCR 评估实验

2026-09-20 用户明确将当前范围收敛为第一可用版，并禁止继续提前实现 OCR。
本分支仅存档调整前已有的隔离实验；这些脚本、评估依赖和模型不进入第一可用版。
没有选定 OCR 后端，没有产品 OCR 功能，没有将实验虚拟环境变成发布环境。

当前产品工作从 `7032c58` 转到 `codex/iteration1-usable`，复用已验证的 P1–P3。
未来是否恢复 OCR，须在第一可用版稳定后重新评估需求、收益、体积、性能和成本。

实验局限：合成样本不是实际用户图库；部分编译产物受到 Zig 0.16 的
`#embed` 本地缓存复用影响，不能用作可运行发布包或据此选择 OCR 后端。
该构建问题也影响普通应用构建，将在第一可用版构建流程中修复。
